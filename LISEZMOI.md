# Répétiteur

Élèves, planning, pointage, paiements et minuteurs. Les données restent sur le téléphone (IndexedDB).

## Mise en ligne
Crée un nouveau dépôt GitHub public nommé `repetiteur`, envoie tout le contenu de ce dossier à sa racine, puis Settings > Pages > Deploy from a branch > main, /(root).
Adresse : `https://TON-NOM.github.io/repetiteur/`. Installe depuis Chrome ou Safari.

## Mise à jour
Change `v1` dans `sw.js` (constante `CACHE`) à chaque envoi de fichiers modifiés.

## Sauvegarde
Ne dépose jamais un fichier de sauvegarde dans le dépôt public : il contient les noms des élèves et les numéros des parents.
